Mobile-first static Instagram media saver interface.

## Important
GitHub Pages only hosts the website. A compatible, permitted media API is still required. The website cannot bypass Instagram restrictions. Do not enter Instagram passwords or cookies. Use only content you have permission to save.

## Publish from an Android phone
1. Create a public GitHub repository named `instavyn`.
2. Upload `index.html` from this ZIP into the repository root and commit.
3. Open repository Settings → Pages.
4. Select Deploy from a branch, choose `main` and `/(root)`, then Save.
5. Wait for the public Pages URL to appear in Settings → Pages.

To use the downloader, expand Downloader connection settings and enter an API URL whose owner permits your use and which supports browser CORS requests from your website.
